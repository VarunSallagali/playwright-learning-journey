# Playwright Learning Journey

This repository documents my learning and hands-on practice with Playwright using the Udemy course by Rakshy Shetty.

## Goals
- Learn Playwright test automation from the basics.
- Practice writing reliable automated test cases.
- Understand locators, assertions, waits, and browser interactions.
- Learn test organization and the Page Object Model.
- Explore API testing and CI/CD integration.

## Tech Stack
- Playwright
- TypeScript / JavaScript
- Node.js
- Git and GitHub

## Topics Covered
-  Playwright setup
-  First test case
-  Locators
-  Assertions
-  Text boxes, buttons, and links
-  Dropdowns and checkboxes
-  Alerts and frames
-  Waits and auto-waiting
-  Multiple pages and tabs
-  Screenshots and reports
-  Page Object Model
-  API testing
-  CI/CD integration

## Learning Approach
I will add my practice programs, test cases, and notes as I progress through the course.

## Purpose
To strengthen my automation testing skills through consistent practice and maintain a record of my learning journey.
